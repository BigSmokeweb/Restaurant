# Restaurant 🍽️

A modern restaurant website built with **Next.js**, **TypeScript**, and **Tailwind CSS**, inspired by the UI/UX of [Barbeque Nation](https://www.barbequenation.com/). This project recreates a sleek, responsive restaurant experience with menu browsing, cart functionality, and an admin dashboard.

🔗 **Live Demo:** https://restaurant-beta-dusky.vercel.app

---

## ✨ Features

- 🏠 Modern, responsive landing page inspired by BBQ Nation
- 🍔 Menu browsing with categories and item details
- 🛒 Cart functionality with session storage persistence
- 📊 Admin dashboard with stats and management tools
- 🎉 Catering pages for events and bookings
- 🎨 Clean UI built with reusable components
- ⚡ Fast performance with Next.js App Router

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** TypeScript
- **Styling:** Tailwind CSS / PostCSS
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/BigSmokeweb/Restaurant.git

# Navigate into the project directory
cd Restaurant

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

---

## 📦 Build for Production

```bash
npm run build
npm start
```
